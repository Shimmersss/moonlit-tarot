## 必修项（按优先级）

### P1：四张新增分层的键色污染与接触关系

`theme-01/04/05/process_layers.py` 只阈值清背景再模糊 alpha，RGB 未去键色；软边会重新混入洋红底。赤月虽清了部分软边绿色，但只处理 `8 < alpha < 254`，全不透明残绿未覆盖。

当前素材中键色特征且 alpha>16 的像素数分别为 8416、182、7670、17975；数值是排查线索，不单独作为视觉判据，梦境本身存在紫色，应结合边缘位置判断。报告见 [key-color-stats.json](key-color-stats.json)。实际左右倾斜截图支持残边结论。

修复要求：单图去溢色/前景颜色恢复，不整图降饱和；黑白灰底检查，保留细毛与金属细节。地面、水纹、岩台与主体共同处理承接，不能把窄岩条作为整套承重面；机械龟与桥台保持连接。修后重新派生线稿、打包图片、渲染与跑网页测试。
